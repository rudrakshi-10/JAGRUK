  # 🚨 JAGRUK – Smart Safety Clip

## 📌 Project Overview

**JAGRUK – Smart Safety Clip** is a smart safety system designed to help a person during an emergency. It provides a simple dashboard where the user can check safety information and quickly use emergency features.

## 🎯 Main Purpose

The main purpose of JAGRUK is to provide quick access to emergency help using **SOS, GPS, emergency contacts, sensors, and nearby help information**.

## 👤 User Registration

The user can create an account by entering:

* Full Name
* Mobile Number
* Email Address
* Emergency PIN
* Preferred Language

The user can also add three emergency contacts:

1. Father
2. Mother
3. Trusted Friend

## 🔐 Login

The user can log in using their **email address and Emergency PIN**. The system also provides options for account reset and creating a new account.

## 🏠 Dashboard

After login, the user can access the main dashboard. It shows:

* Device Status
* GPS Status
* GSM Network
* Battery Level
* User Information
* Emergency Contacts
* Live Sensor Data
* Current Location
* Nearby Emergency Help
* Emergency SOS

## 🚨 Emergency SOS

The SOS button is the main emergency feature. When the user presses SOS, the system is designed to alert the three emergency contacts and include the user's live location.

## 📍 Location & Help

The system provides a current-location feature and a **Find Nearby Help** option. It includes sections for nearby police stations, hospitals, and public help zones.

## 🌐 Languages

The interface supports:

* English
* Marathi
* Hindi

## 💻 Technologies

The project uses:

* **HTML** – Page structure
* **CSS** – Design and responsive layout
* **JavaScript** – Functions and interactions

## 🚀 Future Scope

The project can later be connected with real GPS, GSM, sensors, SMS, calls, cloud services, and mobile applications.

## ✅ Conclusion

JAGRUK provides a simple and user-friendly safety interface that combines emergency contacts, SOS, location, sensors, and emergency-help features in one system.
