# Jagruk
<section class="project-info">
    <h1>🚨 JAGRUK – Smart Safety Clip</h1>

    <h2>Project Overview</h2>
    <p>
        JAGRUK – Smart Safety Clip is a smart safety system designed
        to help people during emergency situations. It provides a simple
        dashboard where users can check their safety information and
        quickly access emergency features.
    </p>

    <h2>Main Purpose</h2>
    <p>
        The main purpose of JAGRUK is to provide quick emergency help
        using SOS, GPS location, emergency contacts, sensors and nearby
        emergency services.
    </p>

    <h2>User Registration</h2>
    <p>
        A new user can create an account by entering their full name,
        mobile number, email address, Emergency PIN and preferred language.
        The user can also add three emergency contacts: Father, Mother
        and Trusted Friend.
    </p>

    <h2>Login</h2>
    <p>
        Users can log in using their email address and Emergency PIN.
        The system also provides options to reset the account or create
        a new account.
    </p>

    <h2>Dashboard</h2>
    <p>
        The dashboard displays Device Status, GPS Status, GSM Network,
        Battery Level, User Information, Emergency Contacts, Live Sensor
        Data, Current Location and Nearby Emergency Help.
    </p>

    <h2>Emergency SOS</h2>
    <p>
        The SOS button is the main emergency feature. It is designed
        to alert all three emergency contacts and include the user's
        live location in the emergency alert.
    </p>

    <h2>Location & Nearby Help</h2>
    <p>
        JAGRUK provides current location access and a Find Nearby Help
        feature. The dashboard contains sections for nearby police
        stations, hospitals and public help zones.
    </p>

    <h2>Language Support</h2>
    <p>
        The system supports English, Marathi and Hindi, making the
        interface easier to use for different users.
    </p>

    <h2>Technologies Used</h2>
    <p>
        The project uses HTML for structure, CSS for design and responsive
        layout, and JavaScript for login, SOS, location, language and
        other interactive functions.
    </p>

    <h2>Conclusion</h2>
    <p>
        JAGRUK combines SOS, location, sensors, emergency contacts and
        nearby emergency help in one simple and user-friendly safety system.
    </p>
</section>
